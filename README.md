# Avito Multi-Page Parser

Браузерное расширение (Chrome Manifest V3) для сбора объявлений с Авито в JSON.

### Возможности:
* Добавляет панель управления прямо на страницу сайта.
* Собирает заголовки, цены, ссылки и описания объявлений.
* Поддерживает постраничный обход с паузами.
* Выгружает готовый результат в `.json` файл.
